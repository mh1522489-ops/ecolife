## 🔭 نظرة عامة

**Eco Life** هو موقع ويب احترافي متجاوب يقدم حلولاً متكاملة في مجال الطاقة المتجددة والاستدامة البيئية. يهدف المشروع إلى نشر الوعي حول أهمية الطاقة النظيفة وتوفير منصة شاملة تربط العملاء بأحدث التقنيات في مجالات الطاقة الشمسية، طاقة الرياح، كفاءة الطاقة، والمنازل الذكية.

> 💡 **الرسالة**: نبني مستقبلاً أفضل من خلال توفير حلول طاقة متجددة مبتكرة تساعد الأفراد والمؤسسات على تقليل البصمة الكربونية وتحقيق الاستدامة.

## 🛠️ الخدمات المتاحة

### ☀️ الطاقة الشمسية
أنظمة شمسية عالية الجودة للمنازل والشركات مع تخزين ذكي وعمر افتراضي طويل.

### 🌬️ طاقة الرياح
توربينات رياح متطورة لاستغلال طاقة الرياح وتوليد الكهرباء بشكل مستدام.

### 🌱 الاستشارة البيئية
دراسات جدوى متكاملة وتقييم أثر بيئي لمساعدتك في اتخاذ القرار الأمثل.

### ⚡ كفاءة الطاقة
حلول ذكية لتحسين كفاءة استهلاك الطاقة في المباني بتوفير يصل إلى 40%.

### 🏠 المنازل الذكية
أنظمة إدارة ذكية متكاملة لمراقبة وتحسين استهلاك الطاقة في منزلك عن بُعد.

### 🌐 الشبكة الذكية
بنية تحتية لشبكات الكهرباء الذكية تتيح توزيع الطاقة بكفاءة ومراقبة لحظية.

## 🧰 التقنيات المستخدمة

```
Frontend Stack:
├── HTML5 (Semantic Elements)
├── CSS3
│   ├── Flexbox & CSS Grid
│   ├── CSS Variables
│   ├── Backdrop Filter (Glassmorphism)
│   ├── CSS Animations & Keyframes
│   ├── Media Queries (Responsive)
│   └── CSS Popover API
├── JavaScript (Vanilla)
│   ├── DOM Manipulation
│   └── Event Listeners
└── SVG (Scalable Vector Graphics)
```

### 🎯 ميزات CSS المتقدمة
- **Anchor Positioning API** — لتثبيت النوافذ المنبثقة
- **Popover API** — نوافذ منبثقة أصلية بدون JavaScript
- **CSS Container Queries** — استعلامات حاوية للمكونات
- **CSS Scroll-Driven Animations** — رسوم متحركة مبنية على التمرير

## 🚀 كيفية التشغيل

### المتطلبات
- متصفح حديث يدعم HTML5 و CSS3 (Chrome, Firefox, Safari, Edge)
- اتصال بالإنترنت (لتحميل الصور من Pexels والخطوط)

### خطوات التشغيل

```bash
# 1. استنساخ المستودع
git clone https://github.com/mh1522489-ops/ecolife.git

# 2. الانتقال لمجلد المشروع
cd ecolife

# 3. فتح الملف في المتصفح
# يمكنك فتح index.html مباشرة أو استخدام Live Server
```

### باستخدام Live Server (موصى به)
```bash
# إذا كان لديك VS Code مع إضافة Live Server
# انقر بزر الماوس الأيمن على index.html → Open with Live Server
```
